# UHUD — Everyday Style

Original UHUD website with its complete images, styling, hover effects, carousels, post previews, and presentation controls.

## Preview locally

Run `npx --yes http-server . -p 8000` in this repository and open http://localhost:8000.

## Deploy

Static website. No build command is needed. Serve the repository root.

## Source fidelity

The 31 website files are copied unchanged from the original UHUD site's published version 12, source commit `d65ab9b71980dcd6243e7d12504b5e4c7c547aca`.
This includes the original 28 assets, HTML, CSS, and JavaScript. The original Google Fonts dependency is retained.
SHA-256 comparisons confirmed that every website file matches the original source exactly.
